# 2026 대구 콘텐츠페어 AI 쇼츠 스튜디오 — 통합 수정 및 확장 구현 계획서 (개정본)

대구1인미디어센터가 주관하는 '2026 대구 콘텐츠페어' 체험 부스(2일간 약 150명 참가)에 최적화된 모바일 웹앱 확장 계획서입니다. 기존 퀴즈, 세션 관리, 요청 제한, 화면 전환 체계를 100% 보존하면서, 신규 템플릿 3종 개편, Gemini 기반 Canva 매직 미디어용 한국어 이미지 프롬프트 생성(최대 120자), 실시간 편집 및 복사, Canva 5단계 제작 안내 및 상태 복원 기능을 안전하게 추가합니다.

## User Review & Critical Decisions

> [!IMPORTANT]
> **사용자 피드백 반영 핵심 원칙 (Phase 2 보완):**
> 1. **Gemini 모델 고정**: 현재 `server.ts`에서 안정적으로 검증되어 사용 중인 **`gemini-3.8-flash` 모델을 유지**하며 임의로 변경하지 않습니다.
> 2. **120자 초과 시 API 재호출 배제**: 생성된 이미지 프롬프트가 120자를 초과할 경우, 불필요한 추가 API 재호출(비용 및 대기시간 발생)을 일절 하지 않고, **사전 검증된 주제별 120자 이하 기본 템플릿 프롬프트로 즉시 대체**합니다.
> 3. **Canva 이동 후 모바일 브라우저 복귀 시 완벽한 데이터 보존**: 참가자가 Canva로 이동했다가 웹앱으로 복귀하더라도 **쇼츠 3단 대본, AI 이미지 원본 프롬프트, 참가자가 수정한 최종 이미지 프롬프트, 선택 주제/키워드가 `localStorage` 및 `App.tsx` 상태에 완전 동기화되어 그대로 유지**되도록 구현합니다.
> 4. **결과 화면 기본 펼침(Expanded) 노출**: 참가자가 결과 화면에 진입하자마자 이미지 프롬프트를 직관적으로 확인하고 바로 수정·복사할 수 있습니다.

## 1. Overview & Core Concept

- **목적 및 가치**: 축제 방문객이 스마트폰으로 1분 미디어 리터러시 퀴즈를 풀고, 선택한 템플릿과 키워드를 바탕으로 Gemini AI(`gemini-3.8-flash`)가 12초 쇼츠 대본 3단과 **Canva 매직 미디어에 바로 넣을 수 있는 한글 이미지 프롬프트(80~120자)**를 생성받아 나만의 세로형 쇼츠 영상을 손쉽게 제작합니다.
- **주요 대상**: 2026 대구 콘텐츠페어 현장 관람객 (초등학생부터 성인까지 모바일 브라우저로 7~10분 내 1인 체험).
- **무중단 안전망**: Canva 매직 미디어를 사용하지 않거나 생성이 지연되는 참가자를 위해 **"기본 이미지로 계속 만들기"** 선택지를 명확히 제공하여 낙오자 없이 모든 참가자가 체험을 완료할 수 있도록 보장합니다.

### 2.2 화면별 UI 개선

1. **주제 선택 화면 (`StudioScreen.tsx`)**:
   - PIXEL QUEST, ON AIR, UPLOAD CHECK의 개성 있는 배지와 게임/방송/체크리스트 그래픽 테마를 반영.
   - 키워드 칩 터치 시 직관적인 태그 입력 및 40자 제한 카운터 유지.
2. **AI 대본 및 이미지 프롬프트 결과 화면 (`ResultScreen.tsx`)**:
   - **영역 A (나의 AI 쇼츠 문구)**:
     - SCENE 01 (0~4초) / SCENE 02 (4~8초) / SCENE 03 (8~12초) 타임코드 명시.
     - 1장면당 1문장(25자 내외) 배지와 개별/전체 복사 버튼 유지.
   - **영역 B (AI로 나만의 이미지 만들기)**:
     - 기본 펼침(Expanded) 상태로 표시하여 즉시 확인 및 편집 가능.
     - 헤더: "AI로 나만의 이미지 만들기" + 안내문: "AI가 만든 설명을 확인하고, 원하는 부분을 바꿔보세요!"
     - 스타일 태그 칩 (예: `16비트 픽셀아트`, `가상 스튜디오`, `모던 정보형 일러스트`).
     - 글자 수 카운터: `(현재 글자 수 / 120자)` — 실시간 업데이트 및 120자 초과 입력 물리적 차단.
     - [프롬프트 복사] 버튼 (수정된 최종본 복사 + 초록색 토스트 피드백).
     - [원래대로] 버튼 (최초 AI 생성값으로 1클릭 복원).
3. **Canva 제작 안내 화면 (`CanvaScreen.tsx`)**:
   - **STEP 1**: 주제 맞춤 캔바 템플릿 열기 (임시 안내 및 외부 링크).
   - **STEP 2**: Canva 편집기 [매직 미디어]에서 한글 프롬프트 붙여넣고 이미지 생성.
   - **STEP 3**: 템플릿 2번째 장면의 기본 이미지를 내가 만든 AI 이미지로 교체.
   - **STEP 4**: 1·2·3장 대본 문구를 더블클릭하여 자막 교체.
   - **STEP 5**: 12초 세로형 영상 확인 후 MP4 저장.
   - **예외 탈출로**: "기본 이미지로 계속 만들기" 버튼 (AI 이미지 생성이 어렵거나 시간 지연 시 기본 템플릿으로 즉시 진행).

## 3. Key Product Decisions & Trade-Offs

### 3.1 이미지 프롬프트 길이 및 재호출 방지 정책 (최대 120자)
- **원칙**: 순수 한국어 1~2문장(권장 80~120자, 절대 최대 120자).
- **초과 시 처리 (사용자 지침 엄수)**: Gemini 응답 후 `Array.from(imagePrompt).length`가 120자를 초과할 경우, **비용 증가와 지연을 유발하는 추가 API 재호출을 일절 하지 않고**, `src/data/fallbackScripts.ts`에 준비된 검증된 기본 프롬프트(120자 이하)로 즉각 치환합니다.
- **문장 훼손 방지**: 임의로 단어 중간을 잘라 문맥이 깨지는 일이 없도록 검증된 템플릿을 안전하게 활용합니다.

### 3.2 Canva 이동 후 모바일 브라우저 복귀 시 데이터 영속성 (Zero Data Loss)
- **저장 계층**:
  1. `App.tsx` 메모리 상태: `script`, `userEditedImagePrompt`, `selectedTopicId`, `selectedMoodId`, `keyword`.
  2. `localStorage` 세션 저장소: `saveUserEditedPrompt()`, `createNewSession()`을 통해 브라우저가 백그라운드로 전환되거나 탭이 리로드되어도 즉시 복원.
- **복귀 시 동작**:
  - Canva 화면에서 [뒤로가기]를 누르거나 브라우저 탭으로 복귀 시, 참가자가 수정한 최종 프롬프트가 입력창에 완벽히 유지됩니다.
  - [원래대로] 버튼을 누르면 AI가 최초 생성했던 `script.imagePrompt`로 복원됩니다.
